# 简陋的火炮稳定器（ESP32-S3，Arduino IDE）

基于 ESP32-S3 + MPU6050 + ELRS 2.4G nano 的两轴火炮稳定器，模拟现代坦克的炮塔稳定，支持遥控和 WiFi 网页两种控制方式。

## 功能

- **俯仰轴（180° 舵机）**：绝对角稳定。车体颠簸时，炮管自动反向补偿，保持惯性仰角。
- **方位轴（360° 角度舵机）**：位置控制。摇杆控制转向速率、积分成炮塔角度，回中即保持当前朝向。
- **控制源**：ELRS 遥控（CRSF 协议）与 WiFi 网页，二者分开切换，互不干扰。

## 硬件

| 部件 | 作用 |
| --- | --- |
| ESP32-S3 | 主控 |
| MPU6050（GY-521） | 测车体俯仰角 / 横摆角速度 |
| ELRS 2.4G nano 接收机 | 遥控输入（CRSF，420000 波特） |
| 360° 角度舵机 | 炮塔方位（位置控制） |
| 180° 舵机 | 火炮俯仰 |

## 接线（默认引脚，可在 `GunStabilizer/config.h` 修改）

| 信号 | ESP32-S3 引脚 |
| --- | --- |
| MPU6050 SDA | GPIO8 |
| MPU6050 SCL | GPIO9 |
| ELRS 接收机 TX | GPIO16（ESP32 RX） |
| 360° 舵机信号 | GPIO4 |
| 180° 舵机信号 | GPIO5 |

供电：

- MPU6050：VCC 接 3.3V 或 5V（GY-521 板载稳压，读不到就换 5V），GND 共地。
- ELRS 接收机：5V，GND 共地。
- 舵机：用独立 5V 电源（舵机吃电大，别从 ESP32 取电），GND 与 ESP32 共地。

 
> 本代码依赖 ESP32 Arduino core 3.x（使用 `ledcAttach` 新 API）。

## 遥控通道映射（0 基下标）

- CH1（下标 0）= 炮塔转向（360° 舵机）
- CH2（下标 1）= 火炮俯仰（180° 舵机）

与发射机实际通道顺序不一致时，改 `config.h` 里的 `CH_TRAVERSE` / `CH_ELEVATION`。

## WiFi 网页控制

1. 手机连 WiFi `GunStabilizer`，密码 `12345678`。
2. 浏览器打开 `http://192.168.4.1`。
3. 勾选「WiFi 接管控制」后，两个滑杆分别控制俯仰和炮塔角度；取消勾选即切回遥控。

网页实时显示车体俯仰角、横滚角、横摆角速度和当前控制源。

## 稳定算法

- 俯仰：`舵机角度 = 目标仰角 − 车体俯仰角`（互补滤波的绝对俯仰角）。
- 方位：`转向速率（摇杆）积分成炮塔角度`，并叠加车体横摆角速度抵消，实现航向保持。

MPU6050 无磁力计，方位轴只能做角速度（航向）保持，不做绝对航向。

## 参数调整

所有引脚、通道、稳定方向、行程、WiFi 名称密码都集中在 `GunStabilizer/config.h` 顶部：

- 补偿方向反了：改 `ELEV_STAB_INVERT` / `YAW_STAB_INVERT` 的符号。
- 炮塔摆角不合适：改 `TRAVERSE_PULSE_SPAN`（500～1000 之间试）。
- 炮塔转速快慢：改 `TRAVERSE_MAX_DPS`。
- 上电自检：调好后把 `SERVO_TEST_ON_BOOT` 改成 0 关闭。
